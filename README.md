# Ask Madha

This repository contains the front-end source code for the Ask Madha project. It is split into two separate applications: a mobile application and a web application.

## Directory Structure

- **`ask-madha-main/`**: The mobile application built with React Native and Expo.
- **`ask-madha-website-main/`**: The web application built with Next.js.
- **`backend/`** and **`data/`**: Additional backend and data resources.

---

## 📱 Running the Mobile App (Expo)

The mobile application is located in the `ask-madha-main` folder.

1. Open your terminal and navigate into the folder:
   ```bash
   cd ask-madha-main
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the Expo development server:
   ```bash
   npm start
   ```

> This will start the Expo Metro bundler. You can press `a` to run it on an Android emulator, `i` to run it on an iOS simulator, or scan the QR code with the Expo Go app on your physical phone to test it there.

---

## 💻 Running the Website (Next.js)

The website is located in the `ask-madha-website-main` folder.

1. Open your terminal and navigate into the folder:
   ```bash
   cd ask-madha-website-main
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

> The website will then be available at [http://localhost:3000](http://localhost:3000).
